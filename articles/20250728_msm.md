# Marginal Structural Models の式と手順

## 式

曝露が $a_1$、$a_2$ であるときの potential outcome に対する期待値を求めるという式になっています。

$\mathrm{E}[Y^{a_0, a_1}]=\beta_0+\beta_1a_1+\beta_2 a_2$

## ざっくり手順

- A1 の傾向スコアを求めて、IPW（Inverse Probability Weight）を求める
- A2 の傾向スコアを求めて、IPW を求める
- A1、A2 の傾向スコアを乗じてモデルに投入する IPW を計算する
- MSMs で推定を行う

# R での実装

## 使用するパッケージ

```r: r
# 
ipw_mod_a1 <- dat %>% 
  glm(A1 ~ 1, data = ., family = binomial(link = "logit"))
p1 <- predict(object = ipw_mod_a1, type = "response")

# ipw for A2
ipw_mod_a2 <- dat %>% 
  glm(A2 ~ factor(A1) + factor(L2) + factor(A1)*factor(L2),
      data = ., 
      family = binomial(link = "logit"))
p2 <- predict(object = ipw_mod_a2, type = "response")

dat <- dat %>% 
  mutate(
    ipw_a1 = case_when(
      A1 == 1 ~ 1/p1,
      A1 == 0 ~ 1/(1-p1)),
    ipw_a2 = case_when(
      A2 == 1 ~ 1/p2, 
      A2 == 0 ~ 1/(1-p2)),
    ipw = ipw_a1*ipw_a2
  )

dat %>% head()

fit <- dat %>% 
  lm_robust(formula = Y ~ factor(A1) + factor(A2), 
      data = .,
      weights = ipw,
      se_type = "HC1")
summary(fit)

```
